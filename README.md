# 🚀 Vectra (VT-Shooter)

<p align="center">
  <b>An immersive 3D / VR arcade shooter inspired by the classic <i>Galaga</i>, built with Unity and C#.</b>
</p>

---

## 🕹️ About the Game
**Vectra** is a fast-paced arcade shooter that brings the retro, nostalgic essence of classic space shooters like *Galaga* into a modern 3D / Virtual Reality environment. Armed with **binary blasters**, players must fend off relentless waves of classic-inspired enemy formations that grow increasingly difficult over time. 

Designed for quick, intense sessions, the game challenges your reflexes through score-based, high-intensity rounds.

---

## ✨ Key Features
* **Classic Arcade Inspiration:** A modern reimagining of the legendary *Galaga* formula adapted into 3D space.
* **Binary Blasters:** Unique dual-weapon mechanic for precise targeting and high-speed action.
* **Progressive Difficulty:** Dynamic enemy spawners that increase in frequency and challenge as the match progresses.
* **100-Second Rounds:** Fast, adrenaline-pumping rounds where every second counts to maximize your score.
* **Immersive Experience:** Built utilizing Unity's XR Interaction Toolkit for smooth controls and performance.

---

## 🛠️ Built With
* **Engine:** [Unity](https://unity.com/) (C#)
* **XR Framework:** Unity XR Interaction Toolkit
* **Version Control:** Git & GitHub

---

## 📂 Project Architecture
The repository is structured following clean Unity development standards (excluding heavy cache and temporary build folders):
* `Assets/` — Contains core scripts (`Bullet.cs`, `Enemy.cs`, `EnemySpawner.cs`, `Gun.cs`, `GameManager.cs`), scenes, prefabs, and materials.
* `Packages/` — Project dependencies and manifest configurations.
* `ProjectSettings/` — Global project configurations, physics, and input mapping.

## ⚙️ How to Run Locally

If you want to clone and run this project in your local environment:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Sama1495/Vectra.git](https://github.com/Sama1495/Vectra.git)

1. Open Unity Hub.

2. Click on Add project from disk and select the cloned Vectra (or VT_Shooter) folder.

3. Open the project using Unity (ensure you match the compatible Unity Editor version).

4. Open the main scene located in Assets/Scenes/ and hit Play!
